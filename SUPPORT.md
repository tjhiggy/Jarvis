# Support

For usage questions, use GitHub Discussions when it is enabled for this
repository. Otherwise, open a sanitized GitHub issue.

Include only safe diagnostic details, such as:

- Jarvis version and operating system
- Node.js and npm versions
- Installation method: native Node.js or Docker
- Selected AI provider and whether it is configured
- Sanitized error category, command name, and steps to reproduce

Do not include credentials, tokens, private identifiers, message contents,
database files, or unredacted logs.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a support request.
