# Security Policy

## Supported Versions

The currently supported release line is `0.1.x`.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting feature when it is enabled for
this repository. If it is not enabled, contact the repository owner privately
through GitHub.

Do not open a public issue containing a secret, private identifier, message
content, reproduction data that exposes sensitive information, or exploit
details that would put users at risk.

Provide a sanitized description of the issue, affected versions, the impact,
and safe reproduction steps where possible. Maintainers will review reports
and respond on a best-effort basis; no response-time guarantee is implied.
