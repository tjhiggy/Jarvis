# Security Policy

## Supported Versions

The currently supported release line is `1.6.x`.

| Version           | Supported |
| ----------------- | --------- |
| 1.6.x             | Yes       |
| 1.5.x and earlier | No        |

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting feature when it is enabled for
this repository. If it is not enabled, open the
[security contact route request](https://github.com/tjhiggy/Jarvis/issues/new?template=security_contact.yml&title=%5BSecurity%20contact%20request%5D%20)
form so a maintainer can provide a secure reporting route.

That public request must contain no vulnerability details. Do not name the
affected component, version, weakness, impact, reproduction steps, exploit
method, secret, private identifier, message content, or sensitive log data.
Its only job is to request a secure route. Do not use the conduct-report route
for a vulnerability.

After a private route is provided, send the sanitized description, affected
versions, impact, and safe reproduction steps through that route. Maintainers
will review reports and respond on a best-effort basis; no response-time
guarantee is implied.
