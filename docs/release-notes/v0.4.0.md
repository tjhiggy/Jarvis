# Jarvis 0.4.0: Crew Profiles

Status: released 2026-08-11.

Jarvis 0.4.0 introduces optional crew profiles as the first Crew Engagement
platform module. Members can create, preview, edit, hide, show, view, and delete
one server-scoped profile. Jarvis renders the member's current Discord display
name and avatar without storing either value in the profile database.

Profiles are disabled by default. A configured administrator enables them with
`/engagement feature action:enable name:profiles`. Every create, edit, and
delete mutation requires a private Confirm or Cancel action. Hidden and missing
third-party profiles return the same neutral response.

This release does not learn profiles from chat, voice, reactions, or external
activity. It does not add an economy, reputation score, moderation authority,
or Discord server-setting permissions.
