# Jarvis v1.4.0: Economy and Progression

Released 2026-08-13.

## Shipped

- Privacy-safe, bounded progression and economy contract for coins, inventory,
  rewards, trading, achievements, XP, voice XP, leaderboards, and custom titles.
- Aggregate-only reporting suitable for the Command Deck.
- Sites migration was not completed in this release. It is tracked for v1.6 in
  [issue #263](https://github.com/tjhiggy/Jarvis/issues/263).

## Boundaries

This release establishes the shared contract and projection foundation. Each
feature remains independently gated, and opt-out/deletion requirements apply to
all retained progression data. The Sites-hosted Command Deck is planned as a
separate staged control-plane migration, starting read-only with Jarvis local as
the source of truth.

## Verification

The release gate includes the full test suite, build, lint, formatting,
documentation validation, dependency audit, and diff checks.
