# Jarvis v0.9.0 Crew Engagement

## Shipped

- `/daily` server-scoped, idempotent MuthaShip Coin reward with opt-out handling.
- `/streak` UTC-day participation streaks with current and longest values.
- `/profile` privacy-aware member profiles with preview, visibility, deletion, and server identity resolution.
- `/roles` allowlisted self-service crew role selection with hierarchy checks.
- Command Deck engagement visibility and aggregate metrics remain available.

## Deferred to v1.0

Persistent teams and the ambassador-card economy were moved to v1.0 because they require separate data-model, moderation, anti-farming, and UX design work. The release does not claim those features are shipped.

## Verification

The release gate includes the full test suite, TypeScript build, lint, formatting, documentation validation, dependency audit, and diff checks. The v0.9 milestone is closed only after the shipped scope passed those gates.
