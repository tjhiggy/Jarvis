# Jarvis v1.0.0 MuthaShip Platform

## Shipped baseline

Jarvis 1.0.0 is the stable platform baseline: the Discord runtime, Command Deck, feature flags, privacy-safe engagement workflows, provider boundaries, scheduler leases, audit and metrics, release checks, and documented local operations are production-ready.

## Deliberately deferred

The former v1.0 board contained unrelated expansion work. Persistent teams, the MuthaShip Coins card economy, moderation automation, tournaments, temporary voice channels, generic webhooks, and external REST integrations now belong to the v1.1 Community Expansion milestone. They are not represented as shipped functionality.

## Release gate

This release requires the full test suite, build, lint, formatting, documentation validation, dependency audit, migration rehearsal, and diff checks. Future features must land as independently reviewed slices with their own rollback and retention evidence.
