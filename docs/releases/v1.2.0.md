# Jarvis v1.2.0

v1.2.0 ships the first bounded expansion-systems foundations. Moderation and
community policies are server-scoped, validated, and non-mutating by default.

## Included

- AutoMod policy evaluation with allow/flag outcomes.
- Administrator warning validation and content-free moderation logs.
- Raid join-spike policy evaluation and temporary voice-room policy bounds.
- Read-only REST and signed webhook boundary contracts.
- Tournament capacity and format validation.
- GitHub Discussions and native GitHub workflow intake. Jarvis no longer
  creates GitHub issues from Discord.

## Verification

- Focused policy suites passed.
- Build, lint, documentation validation, and GitHub Actions verification passed
  on every merged PR.
- v1.2 milestone reached zero open issues before release.

## Boundaries

These foundations do not autonomously punish members, change Discord settings,
create roles or channels, or write to GitHub. Runtime integrations require
separate enablement, Discord smoke testing, and rollback evidence.
