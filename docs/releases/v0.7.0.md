# Jarvis v0.7.0 Community Intelligence release package

**Status:** Prepared for reviewed deployment and release publication.

## What changes

Jarvis v0.7.0 adds intelligence without turning the Discord server into an
unconsented training set. Approved knowledge uses deterministic multi-token
ranking and retains source attribution. `/server-search` searches only
already-retained Jarvis conversation messages in the current channel or
thread. `/my-stats` is private, opt-in, server-scoped, limited to command
totals, retained for 30 days, and deleted when disabled.

Optional `/image generate` is administrator-only, disabled by default, limited
to one configured allowlisted channel, and stores neither prompts nor image
bytes. The local Command Deck shows only aggregate counts and readiness. A
synthetic local evaluation keeps `gemma3:4b` as the workstation's default
Ollama model; `qwen3:4b` remains installed but was slower and less accurate on
the bounded evaluation.

## Storage and rollback

Member statistics create isolated SQLite preference and daily-counter tables
in the existing database. Approved knowledge approvals remain in their current
table. Retained search reuses existing conversation storage. Image generation
adds no content storage. To roll back, stop Jarvis, restore the pre-v0.7 SQLite
backup and WAL state, deploy v0.6.0, rebuild, register commands, and confirm
runtime identity plus Command Deck health.
